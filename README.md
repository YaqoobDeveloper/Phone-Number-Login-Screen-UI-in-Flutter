# Phone Number Login Screen UI in Flutter 📱✨

A modern and clean **phone number login screen UI** built with Flutter.

This project focuses on a polished mobile authentication experience with a simple layout, reusable widgets, and responsive design.

## 🛠️ Built With

- **Flutter 3.47.2**
- **Dart**

## 📋 Requirements

- Flutter **3.47.2** or compatible version
- Dart SDK included with Flutter
- Android Studio or VS Code
- Xcode for iOS development

## ▶️ Run

### 1. Clone the repository

```bash
git clone https://github.com/YaqoobDeveloper/Phone-Number-Login-Screen-UI-in-Flutter.git
```

### 2. Navigate to the project

```bash
cd Phone-Number-Login-Screen-UI-in-Flutter
```

### 3. Install dependencies

```bash
flutter pub get
```

### 4. Run the app

```bash
flutter run
```
